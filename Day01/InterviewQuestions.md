# Interview Questions

## 1. What is Linux?

Linux is an open-source operating system that is secure, stable, and widely used for servers, cloud computing, and software development.

## 2. Why do DevOps engineers use Linux?

Most production servers use Linux. It provides powerful command-line tools, automation, scripting, and supports DevOps tools like Docker, Kubernetes, Jenkins, Terraform, and Ansible.

## 3. What is WSL?

WSL (Windows Subsystem for Linux) allows Linux to run directly on Windows without installing a separate operating system or virtual machine.

## 4. What is the difference between Windows and Linux?

Windows is a commercial operating system mainly used on desktops, while Linux is open-source, highly customizable, and commonly used on servers and cloud platforms.

## 5. Why is Linux widely used on servers?

Linux is stable, secure, lightweight, efficient, and can run continuously for long periods, making it ideal for servers and cloud infrastructure.
